# Harvin's Cafe & Bistro — Digital QR Menu

A single-page mobile menu served as a static site. The QR code on each table links here.

## Deploy on Railway
1. Push/connect this repo to Railway (New Project → Deploy from GitHub repo).
2. Railway auto-detects Node and runs `node server.js` on its `$PORT`.
3. Open **Settings → Networking → Generate Domain** to get a public `*.up.railway.app` URL.
4. Point the table QR code at that URL.

## Instant alternative — GitHub Pages
Served from the `main` branch root at the Pages URL (no build needed).

Menu content: coffee, coolers, shakes and food for Harvin's Cafe & Bistro,
West Side Mall, Tedhi Pulia Ring Rd, Vikas Nagar, Lucknow.
